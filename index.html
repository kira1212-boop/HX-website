Core Features

  • Bare-Metal Installer: Dual-drive sector routing and valid FAT32 formatter engine.
  • TUI Workspace: Hyper-optimized text interface environment featuring row boundary monitoring.
  • HXedit Editor & Auditor: Text creation tool saving directly to sector 50 alongside a dual-pass hex sector auditor.
  • Subsystem Utilities: Low-level calculator processor, real-time motherboard CMOS clock interface, and port cold reboots.

Codebase Architecture

  • boot.asm — Master Boot Sector bootstrap track
  • kernel.asm — Command routing shell layout
  • ui.asm / uicustom.asm — Custom canvas text palette rendering
  • install.asm / partlist.asm — Low-level MBR partition tool chain
  • compiler.asm / software.asm — Embedded multi-language check engine
  • HXcalu.asm / HXedit.asm / Read.asm — Calculator, terminal sandbox editor, and dual-column text parser
